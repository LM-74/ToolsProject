# ToolsProject

## Overview
ToolsProject is a Python web scraping project that demonstrates how to collect, process, and organize data from web pages into structured datasets.

## Features
- **Web Scraping:** Extract data from web pages using Python.
- **Data Processing:** Clean and format the collected data.
- **CSV Export:** Store scraped and processed data in CSV files.
- **Jupyter Notebook:** Explore the scraping workflow interactively.

## Project Files

| File | Description |
|---|---|
| `WebScraping.py` | Python script for web scraping. |
| `WebScraping.ipynb` | Jupyter notebook version of the project. |
| `source.txt` | Saved webpage source used for scraping. |
| `Scraped Data.csv` | Raw scraped dataset. |
| `Formatted Data.csv` | Processed and formatted dataset. |

## Requirements
- Python 3
- Jupyter Notebook (optional)
- pandas
- numpy
- seaborn
- matplotlib
- requests
- bs4
- sellenium
- streamlit

Install the required libraries used by the Python script before running the project.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/LM-74/ToolsProject.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ToolsProject
   ```

3. Run the Python script:

   ```bash
   python WebScraping.py
   ```

   Alternatively, open `WebScraping.ipynb` in Jupyter Notebook to explore the code step by step.

## Output
The project provides CSV files containing the scraped data and its formatted version, also included is a streamlit dashboard viewable by running `WebScraping.py` making the results easier to inspect and analyze.
